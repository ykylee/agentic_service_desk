# M-004 — 구현

설계를 동작으로 옮긴다. 순서·완료 조건·의존·위험은
[`docs/IMPLEMENTATION_ROADMAP.md`](../../../../docs/IMPLEMENTATION_ROADMAP.md) 에 있고,
여기는 **WBS 의 SSOT** 다.

원칙은 넷이다 — 도입 단계(S0~S5)를 따르고, 기반을 한 번에 다 만들지 않으며,
대시보드는 단계마다 조금씩 늘리고, 핵심 경로를 먼저 하고 운영 부가는 뒤로 미룬다.

**4.1~4.4 는 아무것도 내보내지 않는다.**

## WBS

- **WBS-4.1** 기반 — 산출물: 두 프로세스가 뜨고 어댑터가 모 시스템을 읽는다
  - **WBS-4.1.1** 프로젝트 골격 — 산출물: Python 패키지, 설정, 온라인/배치 진입점 분리 (ADR-001, NFR-6)
  - **WBS-4.1.2** 모 시스템 어댑터 골격과 읽기 표면 — 산출물: XR-1~4 (질문·답변(계정)·후속·해결 표시), 외부 입출력 단일 경계 (NFR-2)
  - **WBS-4.1.3** LLM 게이트웨이 — 산출물: 모델 추상화, 온라인 우선 큐, 배치 양보, 로컬 모델만 사용 (ADR-005, NFR-1)
  - **WBS-4.1.4** 저장소 골격 — 산출물: 지식베이스 git 레이아웃(OKF 형식 + 불변 id), SQLite 스키마, 두 저장소 분리 (ADR-002, FR-55, NFR-5)
- **WBS-4.2** S0 수집과 지식베이스 구축 — 산출물: 지식 항목이 쌓이고 Lint 가 안정된다
  - **WBS-4.2.1** 소스 수집 — 산출물: 읽기 전용 전체 클론, fetch, 증분 범위 산출 (FR-1·2, ADR-006)
  - **WBS-4.2.2** QnA 수집 — 산출물: 분 단위 폴링, 작성자 계정·해결 등급 보관 (FR-52, NFR-7)
  - **WBS-4.2.3** 산출물 필터 — 산출물: ingest 입구 단일 집행 지점 (NFR-4, FR-31)
  - **WBS-4.2.4** Ingest 에이전트 — 산출물: 개념 단위 지식 항목 생성·갱신, 출처 부착, 1 ingest = 1 커밋, 설정값 제외 (FR-3·4·5·9·53, ADR-003)
  - **WBS-4.2.5** 모순 표시와 사람 편집 보존 — 산출물: 덮어쓰지 않고 Q4 로, 편집 3조건 (FR-6·54)
  - **WBS-4.2.6** Lint — 산출물: 모순·stale·고아·링크·저장소 간 무결성 (FR-7·8, ADR-002)
  - **WBS-4.2.7** 대시보드 최소 — 산출물: Q4·Q8 대기열과 지식베이스 현황 (FR-44·59)
- **WBS-4.3** S1 수동 등록과 티켓 — 산출물: 승격 A 경로가 실제로 돈다
  - **WBS-4.3.1** 티켓 도메인 — 산출물: 5상태, QnA 항목과 별개 전이 (FR-12·56)
  - **WBS-4.3.2** 종결 기록 — 산출물: 필수 4필드, 무효화 조건 강제 입력 (FR-13·14)
  - **WBS-4.3.3** 질문 직접 등록 — 산출물: 두 칸 입력 + 초안 자동 생성 (FR-10·11, ADR-007)
  - **WBS-4.3.4** 승격 경로 A — 산출물: 종결 기록 → 지식 항목 (FR-15)
  - **WBS-4.3.5** 대시보드 확장 — 산출물: Q1 티켓 대기열 (FR-45·46)
- **WBS-4.4** S2 답변 초안 — 산출물: 초안 품질이 만족스럽다 (반려율이 낮다)
  - **WBS-4.4.1** 검색 — 산출물: 키워드 + 임베딩 + 재랭킹, 사용자 표현 사전 (ADR-004)
  - **WBS-4.4.2** 파이프라인 1~3단계 — 산출물: 분석(언어 판정)·조회·생성, 근거 없으면 티켓 (FR-16~19)
  - **WBS-4.4.3** 불확실성 표시 — 산출물: 진술 단위 3단계 (FR-23, ADR-007)
  - **WBS-4.4.4** 검수 — 산출물: 생성과 분리, P1~P5 반려와 사유 기록 (FR-20~22)
  - **WBS-4.4.5** 대시보드 확장 — 산출물: Q2 답변 검수 대기열
- **WBS-4.5** S3 게재와 추적 — 산출물: 명시적 해결이 쌓이고 커버리지가 오른다
