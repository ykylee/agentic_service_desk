# Agentic Service Desk — 설계

- 문서 목적: 요구사항(M-002)을 구조로 옮긴다. 기술 선택과 그 근거를 **ADR** 로 남긴다. M-003 WBS-3.1 산출물.
- 범위: 컴포넌트 배치 · 프로세스 구조 · ADR 목록 · 요구사항 추적
- 대상 독자: AI agent, 저장소 maintainer
- 상태: draft
- 최종 수정일: 2026-08-28
- 관련 문서: [요구사항](../REQUIREMENTS.md), [컨셉 허브](../../ai-workflow/wiki/concepts/agentic-service-desk-concept.md)

## §1 전제  {#s1-given}

설계에 들어오기 전에 확정된 것들이다. **여기서 다시 논하지 않는다.**

| 항목 | 값 | 출처 |
|---|---|---|
| 지식 저장 | 파일 + git | D12, FR-5 |
| 운영 데이터 | 데이터베이스 | D12, NFR-5 |
| 실행 경로 | 온라인(답변) / 배치(ingest·콘텐츠·Lint) 분리 | NFR-6 |
| 소스코드 반출 | **금지** — 지식 구축은 로컬 LLM | NFR-1 |
| 연동 | 모 시스템 내부 API, 일곱 표면 | D34, XR-1~7 |
| 운영 | **1인 겸업** | D30, CO-7 |
| 도입 | 여섯 단계 S0~S5 | D49 |

### §1.1 이번에 확인한 환경  {#s1-1-environment}

| 항목 | 값 | 영향 |
|---|---|---|
| **GPU 서버** | 있다 | 중형 모델 상시 운용 가능 — O9 · O32 가 크게 풀린다 |
| **구현 언어** | **Python** | LLM · 문서 처리 생태계. pi 하네스와 결이 같다 |
| **대시보드** | 간단한 **웹 UI 신규 구축** | 별도 앱. 모 시스템 관리자 화면에 붙이지 않아 경계가 유지된다 |

## §2 컴포넌트 배치  {#s2-components}

```
 ┌─────────────────── 모 시스템 (외부) ───────────────────┐
 │   소스 저장소(git)              QnA API (7 표면)        │
 └────────▲───────────────────────▲──────────┬───────────┘
          │ fetch (읽기 전용)      │ 폴링/쓰기 │
 ┌────────┴───────────────────────┴──────────▼───────────┐
 │              모 시스템 어댑터  (단일 경계)              │
 └────────┬───────────────────────────────────┬──────────┘
          ▼                                   ▼
 ┌─── 배치 프로세스 ────────────┐   ┌─── 온라인 프로세스 ────────┐
 │  · 소스/QnA 수집             │   │  · 웹 UI (대시보드)        │
 │  · 산출물 필터 (§9.7 단일)   │   │  · 답변 파이프라인          │
 │  · Ingest (구축 에이전트)    │   │  · 게재                    │
 │  · Lint                     │   │                            │
 │  · 콘텐츠 제작              │   │                            │
 └───────┬─────────────────────┘   └────────┬──────────────────┘
         │        ┌─────────────────────────┘
         ▼        ▼
 ┌── LLM 게이트웨이 ──┐   ← 온라인 우선, 배치는 양보 (ADR-005)
 │  로컬 모델 (GPU)   │
 └────────────────────┘
         │
    ┌────┴──────────────────────────┐
    ▼                               ▼
 ┌─ 지식베이스 ──────┐        ┌─ 운영 DB ─────────────┐
 │ 파일 + git        │◀──출처──│ QnA · 티켓 · 답변이력  │
 │ 지식 항목 · 인덱스 │  링크   │ 콘텐츠 이력 · 통계     │
 └───────────────────┘        └───────────────────────┘
```

**모든 외부 입출력이 어댑터 한 겹을 지난다**(NFR-2). 게재의 출구도 그 안에 하나뿐이다(NFR-3).
**산출물 필터는 배치 프로세스 안에 한 지점**으로 둔다 — ingest 입력이 반드시 지나며
우회 경로가 없다(NFR-4).
