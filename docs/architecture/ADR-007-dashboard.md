# ADR-007 — 대시보드 범위와 상호작용

- 상태: accepted
- 결정일: 2026-08-28
- 해소: O28 (알림) · O51 (불확실성 표시) · O55 (등록 부담)
- 관련: [ADR-001](./ADR-001-stack.md)

## 맥락

대시보드는 이 시스템에 사람이 접근하는 **유일한 창구**다(§8.1) — 여기서 못 하는 일은
아무도 못 한다. 그런데 운영자는 **1인 겸업**이고 매일 열어 본다는 보장이 없다(§8.6.3).

## 결정 1 — 화면은 두 종류뿐이다  {#two-screens}

| 종류 | 대기열 | 화면 |
|---|---|---|
| **작업** | Q1 티켓 · Q3 콘텐츠 검수 · Q4 모순 · Q5 정정 | 상세 + 상태 전이 |
| **판정** | Q2 답변 검수 · Q6 암묵적 해결 확인 · Q7 승격 · Q8 지식 공백 | **목록 + 버튼** |

§6.4.4 의 구분을 그대로 화면으로 옮긴다. 판정 화면에는 상태 기계가 없다 —
보고 누르면 끝난다.

**지식 항목 편집기는 만들지 않는다**(D39). Q4·Q5 는 **파일 경로와 지점을 표시**하고,
편집은 운영자의 에디터에서 한다. 대시보드가 할 일은 고친 뒤 **대기열에서 닫는 경로**를
주는 것까지다.

## 결정 2 — 알림은 웹훅 하나 (O28)  {#notification}

1인 겸업이 대시보드를 매일 열지 않는다면, **Q4·Q5 가 쌓여도 아무도 모른다.**
그런데 이 둘은 "틀린 내용이 지금 노출되고 있다"는 뜻이라 방치 비용이 높다(§8.2).

> **위험 대기열(Q4·Q5)의 임계 초과와 국면 역행을 웹훅 한 곳으로 보낸다.**
> 설정하지 않으면 대시보드 배너로만 알린다.

메일 발송 인프라를 두지 않는다는 CO-5 와 충돌하지 않는다 — 그것은 **뉴스레터
대외 발송**에 대한 제약이고, 이것은 **운영자 1인에게 가는 내부 알림**이다. 그럼에도
채널을 하나로 제한해 표면이 번지는 것을 막는다.

## 결정 3 — 불확실성은 세 단계로 표시한다 (O51)  {#uncertainty}

§5.6.5 는 초안이 자기 불확실성을 표시해 **사람이 어디를 볼지** 알려주게 했다.
너무 잘게 나누면 다시 전부 읽게 되므로 **세 단계**로 둔다.

| 표시 | 뜻 | 사람이 볼 곳 |
|---|---|---|
| **확인됨** | 근거 원문에 그대로 있다 | 넘어가도 된다 |
| **추론** | 여러 근거를 엮어 도출했다 | **여기를 본다** |
| **근거 얇음** | 단일·간접 근거뿐이다 | **여기를 먼저 본다** |

진술 단위로 붙인다. 문단 단위면 어디가 약한지 알 수 없고, 단어 단위면 화면이 시끄럽다.

## 결정 4 — 질문 등록은 두 칸에서 시작한다 (O55)  {#manual-entry}

§1.4.4 는 **등록 부담이 크면 유인이 상쇄된다**고 했다. 담당자가 메신저 답변을 마치고
곧바로 남길 수 있어야 한다.

> **입력은 두 칸 — 질문 원문과 담당자가 한 답변.** 붙여넣기로 끝난다.
> 나머지는 시스템이 채운다.

| 항목 | 누가 |
|---|---|
| 질문 · 답변 | **사람** (붙여넣기) |
| 일반화된 질문 · 근거 추정 | 에이전트 초안 |
| **무효화 조건** | **사람** — 강제 입력 지점(§5.6.4) |
| QnA 에도 게재할지 | 사람 (체크박스, 기본 꺼짐) |

사람이 손대는 것은 **두 칸 + 무효화 조건 하나**다. 무효화 조건을 비워 두는 것이
형식적 승인을 막는 장치이므로(D26) 이것만은 줄이지 않는다.

## 대안과 기각 이유

| 대안 | 기각 이유 |
|---|---|
| 대시보드 내 지식 편집기 | D39 — 파일 기반 + 개발자 운영이므로 중복 투자 |
| 알림 없이 대시보드만 | 1인 겸업이 며칠 안 열면 Q4·Q5 가 방치된다 |
| 알림 채널 여럿 | 표면이 번진다. 하나로 제한한다 |
| 불확실성 5단계 이상 | 잘게 나눌수록 전부 읽게 되어 목적을 잃는다 |
| 등록 시 전 필드 입력 | §1.4.4 의 유인이 상쇄된다 |

## 귀결

- 웹훅 대상이 **사내 메신저일 가능성이 높다** — §1.4 가 "메신저와 경쟁하지 않는다"고
  했는데, 알림은 그 채널을 **역방향으로** 쓴다. 모순이 아니라 용도가 다르다
- 불확실성 표시가 **생성 단계의 산출물**이 된다 — 파이프라인 3단계가 진술별 근거
  강도를 함께 내야 한다
- 등록 화면이 단순한 만큼 **에이전트 초안의 품질이 중요**해진다. 초안이 나쁘면
  사람이 결국 다 고치게 되고 부담이 되돌아온다
